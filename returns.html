CUSTOMER CARE

Returns & refunds

Return eligibility, time limits, return shipping costs, refund timing and exclusions must be stated clearly before checkout and must comply with applicable consumer law in each market served.

Policy details to confirm

  • Return window and condition requirements.
  • How customers request a return or report a defect.
  • Return address and whether return authorisation is required.
  • Who pays return shipping in each situation.
  • Refund method and expected processing time.
  • Lost, damaged, defective and incorrect-item procedures.
  • Any lawful product-specific exclusions.

This is a policy preparation page, not a final refund promise. Confirm supplier terms and obtain appropriate legal review before launch.
